# Figures and visualizations

This directory is intended for **approved figures derived from the actual experiments**: image–mask–prediction comparisons, segmentation overlays, training/validation curves and morphometry plots.

**Status:** No experiment figures have yet been added to this public repository. Figures must come from verified research outputs; sample, illustrative or fabricated plots should not be presented as experimental evidence.

For each published figure, document:
- Caption and source experiment
- Dataset version, model/checkpoint and preprocessing
- Metric or method used
- Corresponding notebook/analysis code
- Whether the figure is a representative example or an aggregate evaluation

Do not upload microscopy images without permission to redistribute them.
