# Experimental results

**Status:** Experimental tables and plots are pending validation and public-release approval. The current repository includes the code used to compute segmentation and morphometry measurements, but it does not contain a verified public results table.

Relevant reported measurements in the notebooks include:
- Foreground macro Dice and per-class Dice
- Intersection over Union (IoU) for semantic segmentation
- Prediction-derived morphology: area, perimeter, equivalent diameter, aspect ratio, eccentricity, circularity, solidity and extent, where computed by the analysis notebook

A reproducible release should include the exact run ID, model/checkpoint, dataset version, split, image count, aggregation rules and units. **No numerical benchmark results are asserted here.**
